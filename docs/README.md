# Project Documentation

Your team must create the following documents during
the planning phase:

- problem-analysis.md
- requirements.md
- user-stories.md
- user-flows.md

These documents must be created by your team based
on your understanding of the client brief.

Do not simply copy requirements from another project.

Your team should discuss decisions and document
assumptions where necessary.

## Current feature inventory and team backlog

See [Feature Inventory and Team Issue Backlog](./features-and-team-issues.md)
for the current capability/status summary and proposed, assignable work items.
It distinguishes implemented authentication from prototype screens and API
endpoints that are not yet implemented.
